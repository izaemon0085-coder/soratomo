# そらとも（β版）

**小さな人工衛星を、地上から運用しよう。** 酒田の地上局から、キューブサット（小さな人工衛星）を動かすゲームです。推し活SNS「ともはね」のゲームとしてつながります。宇宙産業の準備の一歩（アイデアノート 2026/11/3 追記）。

本物の宇宙と同じ「むずかしさ」を、やさしく遊べるようにしています。ころとも（ラジコンの小さなロボット）で作った**安全のしくみ**が、そのまま宇宙のルールになっています。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3800
npm test
```

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉。**本番では必ず設定する** |
| `SORATOMO_DATA` | 遊んだ記録の置き場所（ふだんは `data/`。git に入らない） |
| `PORT` | ポート（ふだんは 3800） |

## 遊び方

ミッションは3つ。本物の衛星は約90分で地球を1周しますが、ここでは **2分で1周、3周まで**です。

1. 🏔️ **鳥海山の写真を撮る**：カメラをつけて、鳥海山の上を通るとき（日なたで）
2. 📡 **写真を酒田の地上局へ送る**：衛星が酒田の上を通る、短いあいだだけ通信できる（送るのに6秒）
3. ☄️ **デブリ（宇宙のごみ）をよける**：エンジン噴射は**2人の同意**。1人のときは、フクロウが10秒かけて確かめる（急がない）。よけないとソーラーパネルに当たって、充電が半分になる

**電池**：日なたで充電、地球の影に入ると減る。カメラ・送信は電気を食う。省電力にすると減りが少ない。0 になると衛星が眠ってゲームおわり。

**協力**：管制官が「協力コードを出す」→ 友だちや家族が、はじめの画面で4けたのコードと名前を入れて入る。エンジン噴射は2人そろって押す。

## キャラ

| キャラ | 役目 |
| --- | --- |
| 🦉 フクロウ | 安全の見守り：デブリの知らせ、2人の同意、1人のときの10秒の確かめ |
| 🐱 ヤマネコ | いつもの値と比べる：影の中で、いつもより電池の減りが速いと気づく |
| 🐹 モグ | 通信：写真を地上局へとどける |
| 🐰 ウサギ | 写真が撮れた・ミッション達成のお祝い |

## しくみ（宇宙の本物の考え方）

- **命令の署名**：すべての命令に HMAC-SHA256 の署名（ころともと同じ自前の計算）。番号が前より大きく、時刻が5秒以内のものだけ通す
- **2人の同意**：危ない命令（エンジン噴射）は2人。30秒そろわなければ取りやめ
- **ブラックボックス**：命令と出来事を、ハッシュの鎖で記録。書きかえると分かる
- **通信できる時間だけ**：地上局の上を通るあいだしか、データを送れない
- **電気の予算**：影のあいだを乗りきる電気の使い方

## ともはねとのつながり

- 町の地図の「🛰️ 宇宙」→「ともはねでログイン」（番号はアプリごとにちがう）
- ともはねに知らせるのは、**ミッション達成の数と遊んだ回数だけ**（アカウント画面に出る）。自己ベストのタイムは そらとも の中だけ。達成は1回のゲームで1回だけ数える
- ログインしなくても遊べる（記録は残らない）

## 正直メモ

- ゲームの軌道・電池・通信は、本物をわかりやすく小さくしたもの（本物の数字ではない）
- β版のゲームはサーバーのメモリの中だけ（30分で消える）。遊んだ記録（数）だけファイルに残る
